말하기 지표 분석
말속도·긴 멈춤·말버릇 상대 음량 변화
질문 음성 출력: TTS / 사용자 응답: 한국어 음성 답변
사용 모델 기본값: whisper-1 · tts-1
코드 기본 설정은 전사 whisper-1, 음성 출력 tts-1이다. Web Audio와 전사 시간 정보를 이용해 말속도, 멈춤, 말버릇, 상대 음량 등을 관찰한다. 음성 인식의 불확실성을 발음 오류로 단정하지 않는다. 모델명은 현재 코드 기본값이며 환경 설정으로 변경 가능하다.

“처음에 화면이 느리다고 느꼈을 때, 혹시 어떤 부분에서 가장 답답함을 느끼셨나요?”
채용 공고 기반 첫 질문 → 이전 답변 기반 후속 질문
합성 개발자 대화 검증 기록 발췌
개발자 합성 대화 검증 기록의 frontend_render_performance 첫 번째 turn을 인용했다. 실제 사람의 면접 기록이 아니다. GPT-4.1 기반 생성과 별도 검토가 답변 근거, 반복 여부와 질문의 적합성을 확인한다. 코드상 꼬리질문 입력에는 대화 기록만 전달한다.

피드백 근거: 사용자 답변 원문 인용 및 보완 방향 제시
일반 답변 피드백의 네 기준은 directness, relevance, repetition, organization이다. 문제가 있다는 판정에는 실제 원문 인용을 요구하고 원문 포함 여부를 코드로 검증한다. conciseExample은 원문 사실에 근거한 정리 예시다. 개발자 전용 기준이 적용될 때는 conciseExample을 null로 두고 설명 요소와 보완 질문을 제공한다.

추가 검증 과제
동일인 T → A → 착석 웹캠·조명·마이크 환경 개인별 오탐과 누락
프로젝트 목표: 자신의 자세와 답변을 점검할 수 있는 AI 면접 연습 환경
현재 구현과 남은 검증을 구분해 마무리한다. 실제 영상의 관절 추적, 합성 전체 체험, 대화/화면 기능 검증이 기록되어 있다. 실제 동일인의 웹캠 T/A/착석, 전시장 마이크와 조명, 개인별 오탐/누락 비교가 남아 있다. 향상 효과나 채용 예측 정확도를 주장하지 않는다.
