# 면접 미리보기 · Interview Coach

자세·음성·답변 분석 기반 AI 모의 면접 코칭 시스템 소개. 현재 10장.

- 열기: [HTML 발표](index.html)
- 다운로드: [PowerPoint](Interview-Coach.pptx)
- 조작: 방향키로 이동, F로 전체 화면, N으로 발표 노트 표시. 영상은 재생 버튼으로 시작.

## 시연 자료

T → A → 착석 흐름은 합성 시연입니다. 관절 분석은 공개 스톡 영상에 실제 MediaPipe를 적용한 결과입니다. 실제 참가자 면접 기록이나 동일인의 전체 보정 검증을 의미하지 않습니다. 답변 예시는 합성 개발자 대화 검증 기록입니다.
