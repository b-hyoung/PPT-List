# 견훤, 천년의 귀환

학교 심사용 HTML 발표 자료, 7장. `index.html`을 브라우저로 열거나 PPT List의 발표 카드를 선택합니다.

- 좌우 방향키 / 스페이스바: 슬라이드 이동
- F: 전체 화면
- N: 발표 노트 토글 (슬라이드별 발표 대본 확인)
- 4번: 킨텍스 현장 시연 영상의 무음 자동 반복. 슬라이드를 떠나면 정지합니다.
- 5번: 74초 실제 플레이 영상. 슬라이드에 들어오면 바로 반복 재생합니다(소리가 막히면 무음).

웹 전송을 위해 이미지는 `assets/`로 분리하고 플레이 영상은 720p로 압축했습니다. 이 폴더 전체를 함께 보관하면 로컬에서도 열 수 있습니다.
