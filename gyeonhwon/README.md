# 견훤, 천년의 귀환

학교 심사용 HTML 발표 자료, 7장. `index.html`을 브라우저로 열거나 PPT List의 발표 카드를 선택합니다.

- 좌우 방향키: 슬라이드 이동 / F: 전체 화면
- 4번: 킨텍스 영상의 6–18초 구간을 무음 자동 반복. 슬라이드를 떠나면 정지합니다.
- 5번: 74초 플레이 영상, 클릭 재생
- AI 생성 개념 이미지는 슬라이드에 표시했습니다.

웹 전송을 위해 이미지는 `assets/`로 분리하고 플레이 영상은 720p로 압축했습니다. 이 폴더 전체를 함께 보관하면 로컬에서도 열 수 있습니다.
